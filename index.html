Guía de Montaje en GitHub Pages

¿Por qué la cámara funciona en GitHub Pages?

Los celulares modernos (iOS Safari y Android Chrome) **bloquean la cámara** a menos que la página esté bajo https:// seguro. GitHub Pages ofrece HTTPS gratuito automáticamente, por lo que tus usuarios solo deben presionar "Permitir" cuando el navegador pregunte.

1 Crear el Repositorio en GitHub

Crea un repositorio público (ej: mi-tocadiscos-digital) y sube este archivo con el nombre index.html.

2 Activar GitHub Pages

Ve a Settings → Pages en tu repositorio. En Branch, selecciona main (o master) y presiona Save. En 1 minuto tendrás tu enlace https://tu-usuario.github.io/mi-tocadiscos-digital/.

3 Usar tus propias canciones MP3

Puedes crear una carpeta llamada musica/ en GitHub, subir tus canciones (cancion1.mp3) y mapearlas en el formulario "Crear Nuevo Disco" usando la ruta ./musica/cancion1.mp3.
